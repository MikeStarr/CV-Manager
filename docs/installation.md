# Installation

## Stable release

To install CV Manager, run this command in your terminal:

```sh
uv add CV-Manager
```

Or if you prefer to use `pip`:

```sh
pip install CV-Manager
```

## From source

The source files for CV Manager can be downloaded from the [Github repo](https://github.com/MikeStarr/CV-Manager).

You can either clone the public repository:

```sh
git clone https://github.com/MikeStarr/CV-Manager
```

Or download the [tarball](https://github.com/MikeStarr/CV-Manager/tarball/main):

```sh
curl -OJL https://github.com/MikeStarr/CV-Manager/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd CV-Manager
uv sync
```
